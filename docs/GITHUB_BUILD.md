# GitHub Actions build model

The sample workflow builds a debug APK.

GitHub Actions billing is determined by GitHub's policies, plan, repository visibility, runner type, and usage. Eligible standard GitHub-hosted runner usage for public repositories may be free of Actions-minute charges, but this is not unlimited compute or storage. Private repository usage may consume included minutes and then be billed according to the account's plan and settings.

XCode Studio must not label public-repository builds as absolutely unlimited. Display current quota and billing details from GitHub where available.
